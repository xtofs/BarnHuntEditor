Keyboard shortcuts

Use the mouse and keyboard to edit.

  • b add bale
  • s add start box
  • Click or drag items to select and move
  • ↓ ↑ ← → move selected item
  • Shift + arrows for fine movement (0.1 ft)
  • r rotate selected bale
  • a toggle anchor for selected bale
  • 1 2 3 set bale level
  • Tab / Shift+Tab cycle through items
  • Space deselect current item
  • ␡ ⌫ delete selected item
